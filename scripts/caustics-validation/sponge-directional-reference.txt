# pbrt-v4 reference for the caustics ladder's directional-light rung (menger#150):
# level-2 sponge-volume, size 0.6, glass IOR 1.5, light directional:0.3,-1,0.6, floor y -0.5.
# The fractions of the light the opaque sponge blocks that the glass gives back to the floor,
# inside the shadow footprint (fp) and over the whole floor (all), as sponge_caustics.py defines
# them. Rendered by `compare-sponge-caustics.sh pbrt` (BDPT, 512 spp, floor albedo 0.102, 200x150,
# pbrt-v4 at the commit built on the dev host); stable from 256 to 16384 spp to within 0.002.
# tolerance: the largest relative difference of menger's fractions from these that still passes.
# decided by user 2026-11-17: "0.12 (Recommended)" (relative, on both fractions, plus caustics +
# direct never exceeding the bare floor). menger measures 0.96 and 0.94 of them, run to run
# within 0.01, so 0.12 leaves room for the gather's blur and for a different GPU.
fp 0.393
all 0.569
tolerance 0.12
# Without caustics (optix-jni#132): a shadow ray is a straight line and the light the glass bends
# out of the shadow has nowhere to land, so only the footprint fraction is compared, and a straight
# shadow ray reaches it only to a looser tolerance. decided by user 2026-11-19: 0.15, relative;
# menger measures 0.395 (plain and transparent shadows alike), 0.5% off, deterministic. The same constant of
# optix-jni (GlassShadowConstants::RETENTION, 0.6 of the light a ray lets through stays in the
# shadow; fixed, accepted by user 2026-11-19, lenses use --caustics) gives, against pbrt's footprint fraction, on other scenes (OBJECT, FLOOR_Y env of
# compare-sponge-caustics.sh; menger no caustics / pbrt):
#   sponge, gap object-floor 0.2 (committed scene) / 0.02 / 0.7:  0.395/0.393  0.404/0.399  0.403/0.337
#   cube:                                             0.492/0.480  0.480/0.280  0.496/0.416
#   sphere (a lens):                                  0.553/0.756  0.553/0.070  0.553/0.244
# i.e. within 20% for the sponge, 2-19% (71% at a gap of 0.02) for the cube, and no
# constant fits a lens: where the sphere's focus falls decides what its shadow returns.
fp_tolerance_no_caustics 0.15
